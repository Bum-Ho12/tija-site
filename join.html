Your tester code

Open the link you were sent to see your code here, or use the code from your message.

1. Install Tija

  • Android: Tija on Google Play. If you were invited to a test track, open the invitation first.
  • Windows: coming soon to the Microsoft Store.

2. Enter the code

Either way, you need a Tija account (it's free; you confirm your email with a 6-digit code).

  1. Creating your account now: in Profile → Cloud & Sync, select Enable Cloud Sync, then Have a tester code? and paste the code. It's applied when you confirm your email.
  2. Already have an account: go to Profile → AI Assistant, select Have a tester code?, paste it and select Use code.

What you get

  • A daily AI allowance of 50 requests with Tija Cloud, instead of the normal shared allowance.
  • It lasts for a limited time (usually 30 days) and then ends by itself, and your account goes back to the normal allowance.
  • Codes work for a limited number of people and for a limited time. If yours doesn't work, ask whoever sent it.

The code in this page's address stays in your browser: it isn't sent to our server. See the privacy policy for how tester codes are recorded.
