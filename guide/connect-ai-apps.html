Guide / Connect other AI apps

Connect other AI apps

Let Claude Code, Claude Desktop, Cursor or another app that supports MCP (the Model Context Protocol) search and read your notes and, if you allow it, add and update them.

You need an account with cloud sync turned on. Connected apps only see your synced notes; notes kept only on a device aren't visible to them.

Create an access token

  1. Go to Profile → AI Assistant and scroll to Connect other AI apps.
  2. Select Connect an app.
  3. Enter an App name so you can recognise it later, such as "Claude Desktop".
  4. Decide on Allow changes:
    • Off: the app can only search and read.
    • On: it can also create notes, edit them and tick off tasks.
  5. Select Create token.
  6. Copy the Server address and the Access token.

Copy the token now: it won't be shown again. Anyone with it can use your notes, so keep it private. If you lose it, disconnect the app and create a new token.

You can have up to 10 connected apps. Each one gets its own token.

Set up the app

In the examples below, replace SERVER_ADDRESS and YOUR_TOKEN with the values you copied from Tija.

Claude Code

Tija shows this command ready to copy, with your values filled in. Run it in a terminal:

claude mcp add --transport http tija SERVER_ADDRESS --header "Authorization: Bearer YOUR_TOKEN"

Cursor

Add Tija to Cursor's MCP settings (the mcp.json file):

{
  "mcpServers": {
    "tija": {
      "url": "SERVER_ADDRESS",
      "headers": {
        "Authorization": "Bearer YOUR_TOKEN"
      }
    }
  }
}

Claude Desktop

Claude Desktop connects to servers that need a token through the mcp-remote helper, which needs Node.js. Open Settings → Developer → Edit Config, add this to claude_desktop_config.json, then restart Claude Desktop:

{
  "mcpServers": {
    "tija": {
      "command": "npx",
      "args": ["mcp-remote", "SERVER_ADDRESS", "--header", "Authorization:${TIJA_AUTH}"],
      "env": {
        "TIJA_AUTH": "Bearer YOUR_TOKEN"
      }
    }
  }
}

Other apps

Add a remote MCP server (also called "Streamable HTTP") with the server address, and the header Authorization: Bearer YOUR_TOKEN. Menus differ between apps and change over time, so check the app's own help for where to add it.

What a connected app can do

ToolDoesAvailable
search_notesSearch your notesAlways
get_noteRead a noteAlways
list_tasksList your tasksAlways
list_foldersList your foldersAlways
create_taskCreate a taskWith Allow changes
update_taskChange a taskWith Allow changes
append_to_noteAdd to the end of a noteWith Allow changes
complete_taskTick off a taskWith Allow changes

Changes an app makes sync to all your devices, just like your own edits.

Disconnect an app

In Connect other AI apps, each app shows whether it's Read only or Can read and change notes, when it was added and when it was last used. Select Disconnect next to it. The app loses access straight away; notes it already created stay.

Privacy

Once connected, the app handles your notes under its own terms and privacy policy. We store only a secure hash of each token, never the token itself. See the privacy policy.
