Notes & the editor

A note is made of blocks: paragraphs, headings, lists, checkboxes, quotes, code and images. Mix them however you like.

Start a note

  1. Select Add (the + in the bottom bar or sidebar).
  2. Type a title where it says Title of File/Task.
  3. Write in the first block, or select Add a block.

There's no Save button: Tija saves as you go, once the note has a title or some content.

When you open an existing note it's read-only, so you can't change it by accident. Select the pencil to edit, and the ✓ when you're done.

Blocks and the "/" menu

Type / at the start of a block (or after a space) to change what kind of block it is. Keep typing to filter the list; use ↑ ↓ and Enter to choose, or Esc to close it.

ItemMakes
TextA regular paragraph
Heading 1, 2, 3Large, medium and small headings
Bullet List / Numbered ListLists
CheckboxA task checkbox you can tick
RadioA single-choice option
QuoteA block quote
CodeA code block in a monospaced font
ImageA picture from your device

The same types are in the bar under the editor: Text, H1, H2, H3, Image, List, Number, Check, Radio, Quote and Code. Press Shift + Enter (or Line break) for a new line inside the same block.

With the AI assistant on, the "/" menu also has AI: items such as AI: Summarize. See Writing tools.

The formatting bar

Select some text and use the formatting bar, or a shortcut. On a Mac use ⌘; on Windows and Android keyboards use Ctrl.

ButtonShortcut
BoldCtrl + B
ItalicCtrl + I
StrikethroughCtrl + Shift + X
Inline codeCtrl + E
HighlightCtrl + Shift + H
LinkCtrl + K

Link opens Add link: enter the Text and the Link (starting with https://), then Apply. To change or remove a link later, use Edit link → Remove.

Checkboxes and radio buttons

  • Checkbox items can each be ticked on their own: good for to-do lists.
  • Radio items are for picking one option. Choosing one clears the others in the same group: good for "Venue: A / B / C".

Ticks and choices are saved straight away, and they're kept when you export.

Images, links and tables

  • Images: choose Image and pick a picture. Use Change Image to replace it.
  • Links you add to a note are collected under the editor as References. With the AI assistant on, you can summarize a link from there.
  • Tables: there's no table button yet. You can type a table in Markdown style, with lines that start and end with |; it's kept as you wrote it.

Export as PDF or Markdown

  1. Open the note and select the ⋯ menu.
  2. Choose Export as PDF or Export as Markdown.
  3. Pick where to send or save it from your device's share options.

A note needs both a title and some content to export. Checkboxes and radio buttons keep their state: in Markdown they're written as - [x] and - (x).

Pin, move and delete

From the note's ⋯ menu, or the menu on its card:

  • Pin task keeps it in Pinned.
  • Move to... puts it in a folder.
  • Delete removes it (and from your other devices, if you sync). You can restore it for 30 days from Profile → Data and Storage → Recently deleted.
