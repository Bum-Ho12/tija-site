Guide / AI assistant

AI assistant

An optional helper for capturing tasks, writing, planning and finding things in your notes. It's off until you turn it on, you choose where it runs, and nothing it suggests is saved until you accept it.

Turn it on

  1. Go to Profile → AI Assistant.
  2. Turn on Use the AI assistant.
  3. Under Where requests go, choose Tija Cloud, Your own model or On this device. The sections below explain each.
ChoiceBest forNeeds
Tija CloudThe best answers with no setupAn account; daily allowance
Your own modelUsing a model you run or pay forOllama, LM Studio or an API key
On this devicePrivacy and working offlineA supported device, or a downloaded model

Quick capture

Type a task the way you'd say it, such as "Send invoice to Kamau by Friday 3pm, high priority, remind me a day before", and select Create task. Check the result, then choose Use this or Edit.

Quick capture works even with the assistant off: Tija reads simple dates and priorities on your device.

Writing tools

In a note, type / and pick one:

  • AI: Break down: split into actionable steps.
  • AI: Action items: pull out the to-dos.
  • AI: Summarize: add a short summary of the note.
  • AI: Improve writing: make this block clearer.
  • AI: Continue writing: keep writing from here.
  • AI: Text from image: turn a photo of notes into text (JPEG, PNG, WebP or GIF).

Then choose Insert (or Replace for Improve writing), or Try again.

Write a note, or a template from a note

In Add, open the ✨ menu and choose Write a note. Describe what you need, such as "Meeting notes for a product launch with an agenda and action items", and select Write. Check the title, priority and note, then choose Use this or Edit request. Under the result, ask for a change such as "make it shorter" and it rewrites the whole note.

Create template from this note, in the same menu, keeps a note's structure and drops the details, and opens the result in the template editor.

Edit with AI

Long-press a block (right-click on a computer) to select it, tap more blocks, or use Select all for the whole note. Then choose ✨ Edit with AI and one of:

  • Fix spelling & grammar, Improve writing, Make shorter, Expand, Simplify
  • Friendlier tone, More formal
  • Turn into a checklist
  • Translate… (you pick the language)
  • Ask for a change… (you type what to change)

You see the changes in red and green, or the finished result, before anything is replaced. Choose Replace to apply them, Try again for another go, or close it to leave the note as it was. Replacing is one undo step. If the result would change a block layout line (the lines that make columns), Tija refuses it instead of breaking your layout.

Widgets from a description

Type / and choose Interactive widget, then describe what you want, such as "A tip calculator with a bill, a tip choice and a split between people", and select Build. You can try the widget before you choose Insert, and ask for changes. It is built only from the pieces in Interactive widgets, so it can't run code, open links or reach the network. With a description like "a 25 minute focus timer that flashes and notifies me", it adds a timer with those alerts.

Plan my day and Weekly review

On Home, Plan my day suggests an order for what's due and which tasks to move to later; select Reschedule to move them. Weekly review sums up your week; select Save as note to keep it.

Ask Tija

In search, type a question such as "What did we decide about the venue?" and select ✨. Tija answers from your notes and shows which notes it used under From your notes.

Tija Cloud

Uses Anthropic's Claude through your Tija account. You need to be signed in. Under Model, pick one:

ModelGood forRequests a day if used alone
Claude Haiku 5.5 (default)Fast and light. Best for everyday use.15
Claude Sonnet 5.5Balanced quality and speed.10
Claude Opus 5.5Most capable, for long or complex notes.5

All models share one daily allowance, and heavier models use more of it: the numbers above are how many requests each gives if it's the only one you use. A mix draws from the same allowance. It resets at midnight UTC, and when it runs out no model works until then, so switching models doesn't give you more. Search by meaning has a separate allowance. Every AI result shows which model answered and how many requests you have left today.

Have a tester code?

If you were given a tester code, it gives your account a bigger daily allowance (50 requests a day) for a limited time, shown in Profile → AI Assistant. Enter it under Have a tester code? there, or when you create your account (it's applied once you confirm your email). The access ends automatically, and you go back to the normal allowance.

Your own model

Connect a model you run yourself, or a provider you have an API key for. Your requests go straight from your device to it.

Choose a Service: Ollama, LM Studio, OpenAI, Google Gemini, Mistral, Groq, OpenRouter, or Other (OpenAI-compatible).

Ollama

  1. Install Ollama on your computer and download a model, for example: 
    ollama pull llama3.2
  2. In Tija, choose Ollama. If Tija runs on the same computer, keep the Address http://localhost:11434/v1.
  3. Select Find models, or type the model's name in Model.
  4. Select Test connection. You should see Works: answered a quick-capture request in …s.

Using Tija on your phone with Ollama on a computer? Ollama has to accept connections from your network (set OLLAMA_HOST=0.0.0.0 before starting it). Then use your computer's address on your network, such as http://192.168.1.20:11434/v1. Both devices need to be on the same Wi-Fi.

LM Studio

  1. In LM Studio, download a model and start the local server. To reach it from another device, turn on serving on the local network.
  2. In Tija, choose LM Studio and check the Address matches the one LM Studio shows, ending in /v1.
  3. Select Find models, pick the model, then Test connection.

A provider with your own API key

  1. Create an API key on your provider's website.
  2. In Tija, choose the provider and paste the key into API key.
  3. Select Find models or type a model name, then Test connection.

Your key is stored encrypted on your device and never sent to us. The provider's own prices and privacy policy apply.

"The model can read images"

Turn this on only if your model accepts pictures. It's needed for Text from image. If it's off, images go to Claude instead, but only if the fallback below is on.

On this device

The AI runs entirely on your device: your notes never leave it, and it works offline.

Built into this device

Uses Apple Intelligence (iPhone, iPad and Mac with iOS or macOS 26 or later) or Gemini Nano (supported Android phones). Nothing to download from Tija, though the system may need to download its model first: select Prepare. If it says to turn it on, enable Apple Intelligence (or Android AICore) in your system settings. It isn't available on Windows.

  1. Select Download on a model. Use Wi-Fi: they're large.
  2. When it shows Downloaded., select Try it to check it works.

Models use storage, and memory while running. To free space, select Delete; you can download it again later.

Downloaded models need a 64-bit Android phone. They can't run on older 32-bit-only phones.

If it fails, use Claude

With Your own model or On this device, you can turn on If it fails, use Claude. When your model can't be reached, returns an error or something unusable, or gets more than it can handle, the same request goes to Claude through your Tija account. Pick which Claude model with Fall back to ….

  • It needs an account and counts against your daily allowance.
  • Your note then leaves your device or network.
  • It's on by default for providers with your own API key, and off for Ollama, LM Studio and on-device models.

Report a response

If an answer is offensive, harmful or wrong, select ⚑ Report this response on it. Choose Offensive or harmful, Inaccurate or misleading or Something else, add a comment if you like, and select Send Report. We receive the response, your reason and comment, and which model answered.

Where your text goes

Only what an action needs is sent: the text you type, the open note, a photo you pick, a page you summarize, or for plans and questions a limited selection of relevant tasks. Nothing is sent while the assistant is off.

ChoiceWhere your text goes
On this deviceNowhere
Your own modelStraight from your device to the server or provider you set up
Tija CloudOur server, then Anthropic. Prompts and answers aren't stored.
Claude fallbackSame as Tija Cloud, only when it's on and your model fails
Search by meaningIndexed on our servers; notes not in English go to Voyage AI
